How the Atlas stays current

Nothing is added automatically. A robot finds; a person decides.

  1. Every morning

    At 06:47 IST a GitHub Action searches OpenAlex, arXiv and Europe PMC for new work on radical pairs, protein qubits, magnetoreception and related topics.

  2. Filtered

    Each paper is scored for relevance, checked against a list of journals and preprint servers, and compared with everything already seen.

  3. Proposed

    Each surviving paper becomes a GitHub issue. The curator is notified at once by email and phone.

  4. Decided

    Only the curator's GitHub account can approve. Approval updates this site, the README and the BibTeX file within a minute; a rejection is remembered for good.

Suggest a paper

Know a paper that belongs here? Send it to the curator. Every suggestion is read, and nothing appears on the site until it has been approved.

  • By email: your email app opens with the message ready to send. Nothing is sent from this page.
  • On GitHub: a bot fetches the paper's details for the curator. You need a free GitHub account.

Paste a DOI, an arXiv id like 2501.01234, or the paper's web address.
