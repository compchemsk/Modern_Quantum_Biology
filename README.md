Proteins can now be operated as spin qubits. A fluorescent protein has been initialised, controlled and read out optically. Engineered flavoproteins report spin resonance inside living cells. Radical pairs in cryptochromes are probed with ultrafast and single-molecule methods. This repository gathers the key papers in one place, sorted by theme.

**Curated by** [Soumyajit Karmakar](https://sites.google.com/view/compchemsk/), Department of Chemistry, IIT Kharagpur. Anyone can suggest a paper, either through the website's form (by email or GitHub) or with a [GitHub issue](https://github.com/compchemsk/Modern_Quantum_Biology/issues/new?template=suggest-paper.yml).

## 🤖 How it stays up to date

1. **Every day at 06:47 IST** a GitHub Action searches OpenAlex (all journals), arXiv and Europe PMC (PubMed + bioRxiv).
2. Each new paper is scored for relevance. It is kept only if it appeared in a listed journal or on a preprint server and hasn't been seen before. The settings are in [`config/watch.yaml`](config/watch.yaml).
3. Every candidate becomes a **GitHub issue**, and the curator is notified.
4. The curator replies **`/approve`**, and the paper is added: README, BibTeX and website rebuild themselves. Or the curator replies **`/reject`**, and the paper is never proposed again.

**Nothing is added without the curator's approval.** Only the curator's GitHub account can approve. Suggestions and comments from anyone else are ignored by the robot.
